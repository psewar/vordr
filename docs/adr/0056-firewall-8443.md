# Port 8443 of the hub only for known senders

Backfilled on 2026-10-30, decided on 2026-10-30. Sources: the operator's project notes (finding of 2026-10-29), the
operator's notes (expansion plan of 2026-10-30).

## Context and Problem Statement

In a network without segmentation the hub port 8443 is open to every machine in it. A perimeter firewall does not
filter traffic between hosts of one network; only a host firewall helps.

## Decision Drivers

* Only approved agents and HA should reach the hub.
* A new host must still be able to register.

## Considered Options

* rule on the perimeter firewall (does not see traffic between hosts of one network)
* host firewall on the hub container

## Decision Outcome

Chosen option: host firewall. nftables on the hub container accepts 8443 only from the addresses from which approved
agents and HA have connected, plus HA itself; IPv4 and IPv6. Other ports stay untouched. The onboarding tool adds a new
host's address before its first connection.

### Consequences

* Good, because unknown machines no longer reach the hub.
* Bad, because a host with a new address is blocked until it is added; without the onboarding tool a new host never
  reaches the hub.

### Confirmation

Counter-check: a host not on the list is dropped (the drop counter rises), listed hosts get through, and all agents
and HA reconnect.
